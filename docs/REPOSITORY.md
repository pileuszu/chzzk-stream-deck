# 하나의 저장소에서 개발·실행하기

`chzzk-stream-deck`만 클론합니다. `native/a1-output`은 별도 Git 저장소나 서브모듈이 아니라 이 저장소에 포함된 코드입니다. NDI와 OBS 로컬 소스는 같은 화면·A1 캡처 엔진을 공유하고 출력 부분만 나눕니다.

루트에서 `npm ci`, `npm run build:native`, `npm run app`을 실행합니다. `npm run build:win`은 두 네이티브 모듈과 앱을 함께 패키징합니다. CMake/OBS 헤더·빌드 파일은 `native/a1-output` 아래에서 준비하므로 형제 폴더가 필요하지 않습니다.

## 설정 위치

| 실행 형태 | 캡처 설정·런타임 위치 |
|---|---|
| 소스에서 `npm run app` | `native/a1-output` |
| 배포 앱 | `%APPDATA%/chzzk-stream-deck/a1-output` |

NDI는 `sender.ini`, 로컬 캡처는 `local-capture.ini`를 사용합니다. 현재 등록된 OBS가 외부 경로를 사용하면 앱은 그 경로를 탐지해 기존 설정을 보존합니다. 새 위치로 옮길 때는 아래 이전 명령을 명시적으로 실행합니다. 앱 UI의 모듈 폴더 버튼으로 현재 위치를 확인할 수 있습니다.

## 이전 독립 송신기 폴더 정리

1. NDI 송신과 OBS를 종료하고, 스트림덱도 트레이의 **종료**로 닫습니다.
2. 사용할 앱을 한 번 열어 런타임을 준비한 뒤 다시 종료합니다. 소스 실행이면 네이티브 빌드를 먼저 완료합니다.
3. 새 런타임 폴더에서 `python tools/setup_obs_local.py --relink`를 실행합니다. 배포 앱을 사용할 때는 위의 AppData 런타임 폴더에서 실행합니다.
4. 이전 명령이 기존 NDI·로컬 설정을 새 폴더로 복사하고, OBS 소스의 실행/저장 경로와 A1 Lua 스크립트 경로를 이전합니다. 중지된 소스는 중지 상태를 유지합니다. 이전 로그 폴더를 향하는 녹화 출력 경로도 새 로그 폴더로 바꿉니다. 장면 배치·오디오 믹서·방송 서비스는 보존합니다.
5. 앱에서 설정과 연결 경로를 확인한 뒤 기존 폴더를 `.local-backups/` 아래에 보관할 수 있습니다. 이전 녹화·로그는 원래 폴더에 그대로 남으므로 폴더를 삭제하지 마세요. 백업에 `.git`이 있으면 `git-metadata`로 이름을 바꿔 중첩 저장소로 인식되지 않게 합니다.

이전 명령은 바뀌는 파일의 원본과 복원 경로를 새 런타임의 `logs/obs-relink-*/manifest.json`에 보관합니다. 기존 구성 파일이 없거나 A1 소스가 여러 개면 작업을 중단합니다. 쓰기 실패 시 이미 바뀐 설정은 되돌립니다. 이전 폴더의 파일은 수정하거나 삭제하지 않습니다.

개인 설정과 백업을 Git에 추가하지 마세요. `.gitignore`와 패키징 제외 목록이 캡처 설정·로그·녹화·`.local-backups/`를 제외합니다. 공유할 기본값은 `sender.example.ini`만 수정합니다.

이전 검증: `npm run test:registration`. 임시 OBS 프로필에서 NDI/로컬 설정 보존, 중지 상태, 녹화 경로, 원본 백업과 실패 시 복원을 검사합니다.
