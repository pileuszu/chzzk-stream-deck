# 앱 생명주기

## 사용자 동작

창 닫기는 숨김이며 모듈을 중지하지 않습니다. 트레이 열기와 두 번째 앱 실행은 같은 창을 복원합니다. 트레이 종료는 자원 정리가 성공한 뒤에만 Electron 종료를 허용합니다. 로컬 캡처 중지·NDI 중지·채팅 연결 해제는 해당 모듈만 정리합니다.

## 공통 종료 계층

`src/tray-lifecycle.js`의 `TrayLifecycle`이 창과 트레이의 수명을 관리합니다. 새 백엔드 모듈은 main에서 `lifecycle.register('모듈 이름', () => module.shutdown())`으로 등록합니다. 각 shutdown은 반복 호출을 허용하고 실제 종료 확인까지 Promise를 반환해야 합니다. 화면 패널을 떠나거나 숨기는 동작을 backend shutdown에 연결하지 않습니다.

종료는 새 작업을 차단하고 등록된 모든 정리 작업을 호출합니다. 한 모듈이 실패해도 다른 모듈은 정리합니다. 종료 중 재요청은 같은 Promise를 공유합니다. 실패 시 앱·서버를 유지하고 오류를 표시해 재시도할 수 있게 합니다. 성공 시 HTTP/SSE 연결을 끝내고 트레이와 앱을 종료합니다.

- 출력 모듈은 진행 중인 설정/실행 명령을 기다립니다. OBS A1 소스는 제어 스크립트의 응답과 캡처 정지 상태를 확인합니다. NDI는 전용 `--stop` 명령 후 프로세스 종료를 확인합니다.
- 채팅은 서버 안에서 이벤트 기반 클라이언트로 동작합니다. 연결 해제와 앱 종료 시 인증 요청·WebSocket·하트비트·재연결 타이머를 취소하고 구독을 해제합니다. 종료 중 새 연결 요청은 거절합니다. 별도 채팅 자식 프로세스를 생성하지 않습니다.
- 외부 프로그램 OBS·FL Studio·Voicemeeter는 종료 대상이 아닙니다. OS에서 앱을 강제 종료하거나 전원을 끄는 경우에는 이 정상 종료 절차가 보장되지 않습니다.
- 숨겨진 화면은 출력 상태 조회를 멈추고 채팅 상태 폴링을 건너뜁니다. 실제 캡처와 채팅 서버는 UI 가시성과 독립적으로 실행됩니다.

## 아이콘

루트 `icon.svg`를 원본으로 사용합니다. `npm run build:icons`가 Electron에서 렌더링하여 PNG와 16–256px 다중 해상도 ICO를 만듭니다. Windows 패키징의 afterPack은 해당 ICO를 실행 파일 리소스에 반영합니다.

## 검증

`npm run test:lifecycle`: 숨김/복원, 종료 중복 방지, 실패 후 재시도, 실제 자식 프로세스 종료, 서버·SSE 정리.

`npm run test:outputs`: 종료 중 실행 차단, 진행 작업 대기, 로컬/NDI 정리 순서, 일부 실패 시 나머지 정리.

`npx electron test/smoke-deck.cjs`: 격리된 프로필에서 실제 창·트레이 생성, X 숨김과 복원, 숨김 중 조회 중단, 서버 유지, 트레이 종료. 이 UI 테스트는 실제 사용자 캡처를 중지하지 않도록 네이티브 종료를 대체합니다.
