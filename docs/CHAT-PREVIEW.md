# 채팅 설정 미리보기

채팅 모듈에서 채널 연결, 표시 설정, 채팅 미리보기를 한 화면으로 봅니다. 기본 640×440, 최소 600×420 창에서 모든 설정과 저장 버튼이 보입니다.

- 테마(Simple Purple / Neon Green / Clean), 정렬, 메시지 수, 닉네임 길이를 바꾸면 바로 반영합니다.
- 기본 미리보기는 정지 상태입니다. **재생**으로 메시지 등장과 유지 시간 후 사라짐을 확인합니다. 0초는 사라지지 않습니다.
- 오른쪽 아래 배경 버튼은 미리보기 배경만 밝게/어둡게 바꿉니다. 실제 채팅 배경은 투명합니다.
- 미리보기는 최대 8개의 예시 채팅을 사용하며 설정한 메시지 수가 더 많으면 그 수와 예시 수를 따로 표시합니다. 작은 영역에서 위쪽 메시지가 잘리는 모습은 전체 OBS 캔버스의 배치와 다를 수 있습니다.
- 변경은 **설정 저장** 전까지 미리보기에만 반영됩니다. 예시 메시지는 실제 채팅 스트림으로 보내지 않습니다.
- 다른 모듈로 이동하거나 창을 트레이로 숨기면 재생 타이머를 정리합니다.

## 유지보수

실제 OBS 화면과 미리보기 모두 `src/chat-overlay.html` → `js/chat/overlay.mjs`와 `css/chat-overlay.css`를 사용합니다. 말풍선 마크업·폰트·테마·닉네임 처리 코드는 하나입니다. 미리보기 전용 CSS는 좁은 영역의 바깥 여백과 정지 재생 상태만 조정합니다.

새 테마는 `js/chat/themes.mjs`의 목록과 공통 CSS에 추가합니다. 프리뷰 전용 테마를 따로 구현하지 않습니다. 미리보기 컨트롤러 `ChatPreview`는 모듈의 AbortSignal과 표시 상태를 따릅니다. 미리보기 iframe은 SSE와 저장 설정 폴링을 시작하지 않고 읽기 전용 예시를 렌더링합니다.

검증: `npx electron test/smoke-deck.cjs`로 최소 창 크기, 테마·설정 반영, 유지시간 재생, 저장 격리, 타이머 정리를 확인합니다. `npx electron test/smoke-chat-overlay.cjs`는 격리된 포트와 프로필에서 실제 SSE 수신·저장 설정 적용·HTML 이스케이프를 확인합니다. 실제 CHZZK 채널에는 연결하지 않습니다.
