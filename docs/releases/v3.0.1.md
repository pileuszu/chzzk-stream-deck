# CHZZK Stream Deck v3.0.1

Windows x64 포터블 앱입니다. **CHZZK-Stream-Deck-3.0.1-win-x64-portable.exe**를 다운로드해 실행하세요.

## 이번 릴리스

- 앱과 잠금 파일의 버전을 3.0.1로 갱신했습니다.
- README와 빌드·배포 안내를 갱신하고, OBS 자동 연결에는 Python이 필요하지 않음을 명확히 했습니다.
- 기능과 캡처 엔진은 v3.0.0과 동일합니다. 성능 최적화 변경은 이번 릴리스에 포함되지 않았습니다.

## 사용 안내

로컬 캡처, NDI 송신, CHZZK 채팅을 한 앱에서 관리합니다. 화면·A1 캡처 엔진과 OBS 로컬 플러그인이 포함돼 있습니다.

캡처에는 Voicemeeter, NDI 송신에는 NDI 6 런타임을 별도로 설치해야 합니다. 로컬 캡처는 OBS Studio 32.0.1 x64 기준이며 현재 OBS 장면에 소스를 자동 추가합니다. 연결 실패 시 설정을 유지하고 다시 시도할 수 있습니다.

앱 실행 자체는 모듈을 시작하지 않습니다. 창을 닫으면 트레이로 숨겨져 실행 중인 모듈은 계속 동작합니다. OBS에 캡처 실행 상태가 저장돼 있으면 OBS를 다시 열 때 로컬 캡처가 재개될 수 있습니다.

개인 설정은 사용자 AppData에 보관하며 배포 파일에는 포함하지 않습니다. OBS 플러그인의 대응 소스·빌드 스크립트·라이선스가 앱에 함께 포함됩니다. 첨부된 SHA256SUMS.txt로 실행 파일의 무결성을 확인할 수 있습니다.
