# 덱에서 배치 편집

상단 연필은 편집 모드를 켜고 끄는 버튼입니다. 별도 설정 화면을 열지 않습니다.

- 배정된 모듈을 잡아 빈칸에 놓으면 이동합니다.
- 다른 모듈에 놓으면 두 모듈의 위치를 교환합니다.
- 11번과 15번은 고정 페이지 키입니다.
- 드래그한 채 페이지 키 위에 650 ms 머무르면 기존 페이지를 한 번 넘깁니다. 다시 넘기려면 키 밖으로 나왔다가 들어옵니다.
- 새 페이지는 드래그를 시작하기 전에 마지막 페이지의 + 키를 눌러 추가합니다.
- 빈 페이지에서만 상단 삭제 아이콘이 표시됩니다.
- 놓은 배치는 즉시 저장합니다. 별도 적용 버튼이 없습니다.
- 덱 바깥, 같은 칸, 고정 페이지 키에 놓거나 Esc를 누르면 모듈 배치는 바뀌지 않습니다.
- 편집 중 단순 클릭은 모듈 패널을 열지 않습니다. 연필을 다시 누르거나 선택이 없는 상태에서 Esc를 누르면 편집을 끝냅니다.

키보드 사용자는 Space/Enter로 모듈을 선택하고 방향키로 대상 칸에 이동한 다음 Space/Enter로 놓을 수 있습니다. Page Up/Down으로 페이지를 바꿀 수 있으며 Esc는 현재 선택을 취소합니다.

## 구현

js/deck/core/reorder.mjs의 DeckReorder가 포인터 캡처·미리보기·대상 표시·페이지 호버·취소와 키보드 선택을 담당합니다. 페이지가 바뀌어도 유지되는 grid 요소에서 포인터를 캡처합니다. 다른 앱으로 전환하거나 창 크기가 바뀌면 진행 중인 드래그를 취소합니다.

DeckController.moveModule은 편집 모드와 유효한 모듈 인덱스를 확인한 뒤 이동/교환을 처리합니다. 포인터와 키보드가 이 함수를 공유합니다. 기존 v6 배치 형식과 모듈 ID를 유지합니다. 키의 렌더링은 기존 KeyView를 그대로 사용합니다.

test/smoke-deck.cjs는 실제 Electron 마우스 입력으로 이동, 교환, 포인터 캡처, 페이지 간 이동, 취소, 자동 저장, 편집 중 패널 차단을 검증합니다. 기존 모듈의 설정 패널 및 600×420 레이아웃 검증도 포함합니다.

## 탄성 애니메이션

DeckReorder는 배치·포인터 캡처를, DeckMotion은 시각 효과를 담당합니다. spring.mjs는 시간 간격을 사용하는 감쇠 스프링입니다. 커서에 대한 지연은 85 px로 제한하며 속도에 따라 카드 기울기를 조절합니다. 슬롯 자체의 좌표는 유지하고 카드 표면만 움직여 놓을 위치가 흔들리지 않습니다.

이동·교환은 즉시 저장하고 안착 효과는 이후에 표시합니다. 멈추면 requestAnimationFrame 반복을 쉬고, 편집 종료·창 숨기기·포커스 상실 시 효과를 정리합니다. prefers-reduced-motion에서는 탄성·회전·파동 없이 즉시 배치합니다.

검증: npm run test:motion, Electron test/smoke-deck.cjs.
