# 검증 기록 — 2026-09-13

## 2026-09-14: OBS 원컴 로컬 소스

- OBS Studio 32.0.1 x64용 `a1-local-source.dll`을 빌드하고 별도 `A1 Local` 장면 모음에 `A1 Desktop + Audio` 소스로 등록했다.
- NDI 송신기와 OBS 소스는 동일한 `AlignedCapture` 코드로 A1 직접 캡처, 화면 큐, 샘플 시계, 500ms 버퍼와 오디오 오프셋을 처리한다. OBS에는 압축 전 UYVY 영상·float 스테레오 PCM을 공통 시각으로 직접 제공한다.
- 로컬 소스는 NDI 전송을 사용하지 않는다. 기존 NDI 송신기는 종료했고 OBS의 NDI 메인·미리보기 출력도 껐다. 설치된 DistroAV 플러그인의 런타임 로딩 여부와 로컬 소스의 전송 경로는 별개다.
- 최초 시험의 초기 오디오 지연 경고를 확인하고, 이미 기다린 영상·오디오의 타임스탬프를 동일하게 OBS의 현재 시간축으로 옮겨 해결했다. 추가 대기나 영상 대비 오디오 보정은 넣지 않았다.
- NVENC H.264 / AAC를 사용한 합성 신호 실제 OBS 녹화: 약 14.76초, 영상 444프레임, 15개 플래시·997Hz 톤 이벤트. 오디오-영상 차이 중앙값 **-12.249ms**(소리가 먼저), 관측 범위 약 -12.283~-12.229ms. 30fps 한 프레임보다 작은 차이이며, 0ms 또는 물리적 완전 동기화를 주장하지 않는다.
- 합성 시험 분석: `logs/obs-local-synthetic-analysis.json`. 실제 데스크톱·A1 녹화와 소스 스크린샷도 로컬에 저장해 화면 방향·색상·내용과 오디오 트랙을 확인했다.
- 실제 캡처 상태 관측: 1920×1080 30fps, 48kHz 스테레오, 오디오·영상 큐 넘침/늦은 작업 폐기 0, 재연결 0. 최종 판단에는 아래 NDI 시험과 동일하게 실제 사용 환경의 추가 검증이 필요하다.
- `audio_offset_ms=0`, `calibration_verified=false`를 유지했다. 합성 시험 결과를 A1 하드웨어 경로 보정값으로 적용하지 않았다.

이하 기록은 이전 NDI 송출 모드의 검증 결과이다.

- 오디오·영상 큐 넘침, 오래된 프레임/소리 폐기, 잘못된 오디오 블록, 장치 재연결 모두 0.

- 관측 로그에서 송신기 CPU는 전체 시스템 기준 대략 4~6%, 메모리는 약 220~226MB. 동일 조건 OBS 비교 실험은 하지 않았으므로 상대적인 효율 개선 수치는 주장하지 않음.
- 최종 점검 시 `obs64` 프로세스는 실행 중이지 않았고, 전용 송신기 프로세스가 동작 중임.
- 정상 종료 시 상태 파일이 `running:false`로 바뀌는 것을 확인했다. 최종 빌드 재실행 후 약 60초 시점에도 정상 캡처·약 60fps 송신·버퍼 넘침 0을 확인했다.

처음 수신 검사에는 Python 도구가 첫 프레임 PNG를 저장하면서 멈춘 구간이 있었다. 저장을 관측 이후로 옮기고 NDI 공식 권장처럼 영상·오디오 수신 스레드를 분리한 뒤 위 결과로 다시 검증했다. `live-probe.json`은 이 수정 전 결과이며, 최종 판정에는 `live-probe-final.json`을 사용한다.

## 합성 AV 시험

알려진 시각에 흰 화면과 997Hz 톤을 만들어 NDI로 내보낸 시험에서는 15개 이벤트가 같은 시간축으로 전달됐다. 검출 기준에 따른 잔여 차이는 약 0.02~0.04ms였다. 이는 **송신기·NDI 타임코드 처리 검증**이며 실제 A1/모니터/수신 OBS의 물리적 오차를 의미하지 않는다.

`tools/analyze_sync.py`도 이 합성 시험 파일에서 일정한 이벤트 대응을 확인했다. 설정에 합성 시험 결과를 적용하지 않았다.

## 적용 상태와 남은 검증

- `buffer_ms=500`
- `audio_offset_ms=0`
- `calibration_verified=false`
- 시간 기준: DXGI QPC 화면 시각 + Voicemeeter 콜백에서 복원한 샘플 시계.

**실제 재생 콘텐츠의 화면/A1 시간차와 다른 PC OBS 녹화까지 완전히 맞았다고 검증한 상태는 아니다.** A1에 이미 섞인 소리들의 상대적인 타이밍은 그대로 전달하지만, Voicemeeter API가 제공하지 않는 최종 ASIO 하드웨어 출력 시각은 직접 읽지 못한다. 필요하면 알려진 기준 영상을 실제 경로로 캡처해 보정하고 다시 확인해야 한다.

현재 물리 랜 링크는 100Mbps로 확인됐다. 이 PC 안의 로컬 수신 시험은 기가비트 공유기 연결 후 다른 PC에서의 전송 안정성을 대신하지 않는다. 장시간 방송·네트워크 혼잡·장치 재연결에 대한 실사용 검증도 아직 완료하지 않았다.

측정에 사용한 원본 로그·영상·오디오는 로컬 `logs/`에 보관하며 저장소에는 포함하지 않는다. 이 문서는 해당 환경에서의 관측 결과이며, 다른 하드웨어·드라이버·네트워크에서 동일한 결과를 보장하지 않는다.
